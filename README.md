## 🚀 Quick Setup
1. Clone repository:
```bash
git clone https://github.com/Hafiz-sustswe/portfolio.git
cd portfolio
```
2. Open `index.html` directly in browser
3. Or use local server:
```bash
python -m http.server 8000
```

## 🎨 Customization Guide
### Update Personal Info:
1. Edit `index.html` - Name, title, contact details
2. Replace images in `img/` folder
3. Update social links in contact section
4. Modify colors in CSS variables

### Add New Projects:
```html
<div class="portfolio-item">
    <img src="img/projects/new-project.jpg">
    <div class="hover-items">
        <h3>Project Title</h3>
        <p>Brief description</p>
        <a href="github-link"><i class="fab fa-github"></i></a>
    </div>
</div>
```

### Add Publications:
Update publications section with paper details including title, authors, journal, date, and DOI.
